# Saftpresse

Persönlicher Nachbau der eingestellten Juuzo-App: Gemüsesaft-Rezepte für den Slow Juicer.

- 46 Rezepte in vier Geschmacksgruppen (Grün & frisch, Wurzel & erdig, Herzhaft, Shots), inkl. Walker-Rezepte und Rezeptbuch „Gemüse im Glas“
- Mixer mit Zutatensuche („Enthält diese“ / „Nur diese“)
- Farbrad, Mengenrechner, Einfüll-Reihenfolge für den Slow Juicer
- Gesundheits-Tab mit Einordnung der Studienlage
- Programme und Verlauf der getrunkenen Säfte
- Zutaten-Wissen mit eigenen Cliparts
- Läuft offline als Web-App (Home-Bildschirm)

Kalorien, Ausbeute und Gemüseanteil sind Richtwerte aus den Grammangaben. Keine medizinischen Wirkversprechen.

## Installation auf dem iPhone

In Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Favoriten und Verlauf werden nur lokal im Browser gespeichert.
